# DREAMAGY (Project Memory)

## 1. Vision & Overview
**Dreamagy** — интерактивный, минималистичный floating-виджет и системный трей для мониторинга лимитов и квот моделей **Google Antigravity** (Gemini 3.8 Flash, Gemini 3.1 Pro, Claude Sonnet/Opus, GPT-OSS) в реальном времени.

Проект вдохновлен эстетикой [Quotty](https://github.com/confeden/Quotty):
- Тонкая парящая плашка (dark glassmorphism / matte obsidian `#101317`).
- Живые прогресс-бары с динамической цветовой индикацией (зеленый -> желтый -> оранжевый).
- Минималистичные пузырьки/микро-частицы, плавающие внутри капсулы прогресс-бара.
- Четкое разделение пулов квот: Gemini (5-hour limit) и Claude & GPT (Claude & GPT).
- **Кастомный питомец-компаньон: Эллиот Алдерсон (Mr. Robot / Рами Малек)** в черном худи с фотореалистичным рендерингом и анимациями.

## 2. Архитектура системы

### A. Провайдер данных (`antigravity_provider.py`)
- Antigravity запускает локальный языковой сервер (`language_server.exe` или `language_server_windows_x64.exe`), слушающий `127.0.0.1` по протоколам HTTPS и HTTP.
- Провайдер находит PID процесса через `Win32_Process`, извлекает одноразовый `--csrf_token <uuid>`, находит слушающий порт HTTPS и делает RPC-запросы:
  - **Endpoint 1 (Статус и профиль)**: `https://127.0.0.1:<PORT>/exa.language_server_pb.LanguageServerService/GetUserStatus`
  - **Endpoint 2 (Точные недельные и 5-часовые квоты)**: `https://127.0.0.1:<PORT>/exa.language_server_pb.LanguageServerService/RetrieveUserQuotaSummary`
  - **Protocol**: Connect Protocol (`Connect-Protocol-Version: 1`, `Content-Type: application/json`)
  - **Header**: `X-Codeium-Csrf-Token: <CSRF_TOKEN>`
  - **Body**: `{"metadata":{"ideName":"antigravity"}}`
- **Ответ сервера**: `RetrieveUserQuotaSummary` возвращает точные группы бакетов: `gemini-weekly` (недельный лимит Gemini с реальным `remainingFraction` и `resetTime`), `gemini-5h` (5-часовой лимит Gemini), `3p-weekly` (недельный лимит Claude/GPT) и `3p-5h` (5-часовой лимит Claude/GPT). `GetUserStatus` дополняет данные информацией о тарифе (`userTier`, `planStatus`) и моделях.

### B. Графический движок UI (`widget.py`, `pet_elliot.py`)
- **PyQt5** (аппаратно-ускоренная векторная отрисовка через `QPainter` с `Antialiasing` и `SmoothPixmapTransform`).
- Флаги окна: `FramelessWindowHint | WindowStaysOnTopHint | Tool` (плавает поверх всех окон, не засоряет панель задач).
- Прозрачный фон: `WA_TranslucentBackground`.
- Поддержка свободного Drag-and-Drop в любое место экрана.
- Контекстное меню по правой кнопке мыши (ПКМ) и системный трей:
  - Включение / выключение компаньона Эллиота.
  - Прикрепление / открепление Эллиота от плашки (docked / detached).
  - Масштабирование размера питомца: Маленький (0.75x), Нормальный (1.0x), Большой (1.25x), Огромный (1.5x).
  - Настройка прозрачности (100%, 95%, 85%, 70%, 50%).
  - Сброс позиции окна.
  - Принудительное обновление квот.
  - Выход.

### C. Персонаж-питомец: Эллиот Алдерсон (`pet_elliot.py`)
- Фотореалистичный арт персонажа в стиле Mr. Robot на основе вырезанного прозрачного фото-ассета (`assets/elliot.png`).
- Плавные 60 FPS циклы:
  - **Idle**: фаза дыхания (микро-смещение по вертикали и масштабирование груди).
  - **Blink**: естественное периодическое моргание с оверлеем цвета кожи.
  - **Micro-glance**: параллакс-сдвиг взгляда в сторону.
  - **Click reactions**: случайный выбор из 3 действий (быстрое моргание с RGB-глитчем; покачивание всей фигуры "машет рукой"; резкий косой взгляд с приподнятой бровью).
  - **Keyboard typing reaction**: глобальный отлов нажатий клавиш через `win32api.GetAsyncKeyState` — при активном наборе текста Эллиот переходит в сосредоточенный режим "хакинга" (микро-джиттер корпуса и взгляд вниз) с затуханием через 1 сек.
  - **Docked / Detached**: может сидеть прямо на плашке или перемещаться как отдельное окно.

## 3. Файловая структура проекта
```
Desktop/dreamagy/
├── MEMORY.md                 # Данный файл архитектуры и памяти
├── config.json               # Пользовательские настройки (координаты, прозрачность, видимость)
├── antigravity_provider.py   # Поиск language_server и получение квот
├── pet_elliot.py             # Интерактивный процедурный питомец Эллиот (Mr. Robot)
├── widget.py                 # Парящий Quotty-виджет с барами квот и частицами
├── tray.py                   # Иконка в системном трее Windows
├── main.py                   # Точка входа приложения
└── run.bat                   # Скрипт быстрого запуска
```

## 4. Гайд по стилю и эстетике
- **Фон виджета**: `rgba(18, 21, 26, 0.94)` с размытой рамкой `rgba(255, 255, 255, 0.08)`.
- **Цветовая дифференциация квот**:
  - `> 40%`: Неоновый мятно-изумрудный `#2ecc71` / `#10b981`.
  - `15% - 40%`: Кибер-янтарный `#f59e0b`.
  - `< 15%`: Неоновый коралл `#ef4444`.
- **Частицы**: всплывающие микро-точки с затуханием прозрачности на переднем крае заполнения.
- **Шрифт**: `Segoe UI`, `JetBrains Mono` или системный сан-сериф с четким сглаживанием.
