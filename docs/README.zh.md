内置多角色桌面伴侣，为你的编程工作增添乐趣：
* **9 位动态角色**：艾略特（《黑客军团》）、回形针（Clippy）、Linux 企鹅（Tux）、2B（《尼尔：机械纪元》）、时雨羽衣（Ui）、Dario Amodei、特朗普和 Slavik。
* **键盘打字响应**：打字时伴侣会自动奔跑或专注审查代码，艾略特会前倾专注敲击终端。
* **互动气泡对话**：点击伴侣触发霓虹气泡框趣味台词。
* **双模摆放**：支持固定在部件旁或分离为自由悬浮窗口（缩放 0.75x 至 1.5x）。

---

## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Gear.png" alt="Features" width="28" height="28" /> 核心特性

* **无需配置与 API Key**：自动连接本地 Antigravity 语言服务器（`127.0.0.1`）。
* **100% 离线与隐私安全**：完全本地运行，无外网请求与遥测。
* **黑曜石毛玻璃美学**：半透明悬浮窗，支持自由拖拽与记忆窗口位置。
* **丰富个性化设置**：自定义透明度、系统字体（`Segoe UI`、`JetBrains Mono`）、配额显示行数与托盘菜单。

## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Rocket.png" alt="Launch" width="28" height="28" /> 安装与快速上手

```bash
# 1. 克隆仓库
git clone https://github.com/shawermun/dreamagy.git
cd dreamagy

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行
python main.py
```

> **提示**：Windows 用户可直接双击运行 **`run.bat`**。如需开机自启，将 `run.bat` 的快捷方式放入 `shell:startup` 文件夹即可。
